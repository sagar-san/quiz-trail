Question 1 of 10Medium · Building agents using low-code tools

A retail agent correctly routes large refunds to a supervisor page, but a direct request to its refund API can still issue them. Where should the mandatory approval check also be enforced?

  1. In a document ACL that hides the refund policy from customers.
  2. In the refund service, using transaction-bound authenticated approval.
  3. In a model-based response evaluator after each conversation completes.
  4. In an additional low-code route that repeats the supervisor prompt.
Show answer and explanation

Answer: B

Correct answer: B. Conversation routing is not the security boundary for a callable API. The service must reject an unapproved action. Another route cannot protect direct calls; hiding policy is unrelated; retrospective evaluation detects rather than prevents unauthorized refunds.

Question 2 of 10Medium · Building agents using low-code tools

A migration retains document text but drops source URIs and page references. Answers remain broadly accurate, but compliance reviewers cannot locate the supporting passage. Which remediation is most appropriate?

  1. Increase the retrieved context until the entire document fits.
  2. Carry source identifiers and passage locations through the ingestion pipeline.
  3. Ask the generator to infer likely page numbers from section headings.
  4. Replace source citations with an overall confidence score.
Show answer and explanation

Answer: B

Correct answer: B. Citations require traceable evidence identifiers. Inferred page numbers can be fabricated, full-document context does not restore lost identifiers, and confidence is not provenance. Re-ingest affected records where necessary.

Question 3 of 10Hard · Developing custom agents

A support agent handles routine classification and occasional difficult investigations. A smaller model meets classification targets but fails investigation tests; a stronger model meets both at higher measured cost. Which design should be evaluated first?

  1. Use the stronger model for every request without measuring the additional cost.
  2. Select models randomly so usage is distributed evenly.
  3. Route classification to the smaller model and investigations to the stronger one.
  4. Use the smaller model for every request and increase retries on failed investigations.
Show answer and explanation

Answer: C

Correct answer: C. Task-based routing uses the observed quality boundary. Repeated weak attempts may compound failure and cost; always using the stronger model can work but ignores the demonstrated cheaper path; random routing is unrelated to task requirements. Evaluate routing errors and end-to-end quality.

Question 5 of 10Hard · Developing custom agents

A team uses an embedding model that supports RETRIEVAL_QUERY and RETRIEVAL_DOCUMENT. It is indexing policy passages for user search. Which configuration matches this asymmetric retrieval use case?

  1. Embed corpus passages as RETRIEVAL_DOCUMENT and search inputs as RETRIEVAL_QUERY.
  2. Embed the corpus as RETRIEVAL_QUERY and search inputs as RETRIEVAL_DOCUMENT.
  3. Embed both passages and search inputs as CLASSIFICATION.
  4. Embed both sides as SEMANTIC_SIMILARITY because their wording must be identical.
Show answer and explanation

Answer: A

Correct answer: A. Document and query task types optimize the two roles in retrieval. Classification serves another objective; reversing roles is inappropriate; semantic-similarity mode is not the recommended retrieval setting. Task-type interfaces vary by embedding model, as the stem specifies.

Question 6 of 10Hard · Developing custom agents

The correct troubleshooting passage consistently appears among the first-stage top 50 candidates but below the five passages sent to the model. Which change most directly targets this bottleneck?

  1. Rerank the existing candidate set and measure final-context relevance.
  2. Increase output-token capacity while continuing to supply only the existing top five passages.
  3. Change the corpus parser despite verified correct extraction of the relevant passage.
  4. Lower generation temperature while preserving the current candidate ordering and context.
Show answer and explanation

Answer: A

Correct answer: A. The relevant evidence is already among candidates but excluded from final context. Reranking targets selection precision. Output limits and sampling do not expose omitted evidence; reparsing does not address the demonstrated ranking defect.

Question 8 of 10Medium · Developing custom agents

A procurement agent delegates negotiation to a separately deployed supplier agent that manages its own reasoning and task lifecycle. It also calls a currency-conversion function. Which protocol pairing best fits?

  1. A shared vector index as the execution protocol for both operations.
  2. A2A for the function and raw prompt sharing as the only agent interface.
  3. MCP for every interaction because remote agents cannot manage tasks.
  4. A2A for supplier-agent collaboration and MCP for standardized function access.
Show answer and explanation

Answer: D

Correct answer: D. A2A is designed for agent collaboration, while MCP exposes tools and resources. The alternatives confuse service roles or substitute storage for execution. Authentication, authorization, and task contracts remain necessary with either protocol.

Question 9 of 10Medium · Evaluating and deploying agentic workflows

A team repeatedly edits a prompt against the same 40 cases until all pass, then reports that score as unseen performance. What should change?

  1. Ask a second model to paraphrase the same answers and call them unseen.
  2. Evaluate the frozen candidate on independently held-out cases.
  3. Rename the 40 cases before the final scoring run.
  4. Increase the number of runs on the development cases without new coverage.
Show answer and explanation

Answer: B

Correct answer: B. Repeated optimization can overfit the test set. Held-out cases provide more independent evidence. Renaming or shallow paraphrases do not reliably remove leakage, and repeated runs measure variation on known cases rather than generalization.

Question 10 of 10Medium · Evaluating and deploying agentic workflows

A new Cloud Run agent revision passes offline evaluation. The team wants limited production exposure with a rapid return to the prior revision if task success falls. Which rollout best fits?

  1. Shift traffic gradually with measured gates and a retained rollback revision.
  2. Run only unit tests and assume production task success is unchanged.
  3. Send all traffic immediately and delete the previous revision.
  4. Change model, prompt, tools, and data simultaneously without version tracking.
Show answer and explanation

Answer: A

Correct answer: A. Gradual traffic allocation and a retained known-good revision support controlled rollout and rollback. Offline evidence does not cover every production condition; removing rollback or changing many untracked components increases recovery and diagnosis difficulty.
